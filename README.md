# Spoofed Packet Sender
This Python script demonstrates how to craft and send TCP packets with spoofed MAC and IP addresses using the Scapy library. It is intended for educational and authorized testing purposes only.

## Description
The script defines a function, send_spoofed_packets(), which does the following:

* **Crafts a Packet:**
Combines an Ethernet frame (with spoofed source and target MAC addresses), an IP header (with spoofed source and target IP addresses), and a TCP segment (with a random source port generated by Scapy’s RandShort() and a target port specified by the user). The TCP segment is marked with the SYN flag for a typical connection initiation.

* **Displays Packet Details:**
Uses packet.show() to print the packet’s details. This is useful for verifying that the packet is constructed as expected.

* **Sends the Packet:**
Uses the sendp() function to transmit the packet at layer 2. The number of packets sent is determined by the count parameter.

* **Error Handling:**
Catches exceptions such as PermissionError (which indicates that the script must be run with root/administrator privileges) and other generic exceptions.

## Code Explanation
* **Importing Modules:**
The script imports everything from Scapy, which provides the functions necessary for packet crafting and sending, and also imports the sys module for exit handling.

* **`send_spoofed_packets()` Function:**
This function takes the destination IP/MAC, the spoofed source IP/MAC, the target port, and the number of packets to send. It constructs a packet by stacking layers:

```python
packet = (Ether(src=src_mac, dst=dst_mac) /
          IP(src=src_ip, dst=dst_ip) /
          TCP(sport=RandShort(), dport=dst_port, flags="S"))
```

It then:
* Displays the packet details for verification using packet.show().
* Sends the crafted packet using sendp() at layer 2.
* Handles errors—specifically, it prompts you to run the script with proper permissions if needed.
